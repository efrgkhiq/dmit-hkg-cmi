## CMI 是什么，为什么"支持 CMI"这四个字说明不了什么

CMI 是 China Mobile International，中国移动国际，AS 号 58453。香港 VPS 说"走 CMI"，意思是这批流量的跨境段交给中国移动的国际网络，而不是走电信 163 骨干（AS4134）、联通 4837，或者 NTT、Lumen 这类国际运营商。

对移动用户来说，这条路的逻辑接近"回家"：国内移动网络 → 移动国际 → 香港机房，中途不换东家，链路短、转接少。移动宽带访问香港节点，CMI 在延迟和高峰期稳定性上通常比较舒服。

问题出在"CMI"经常被写得含糊：

- 有的是**去程**走 CMI，回程走别的。去程影响你上传和发请求，回程影响你打开网页、下载、看视频。日常体感主要看回程。
- 有的是双向都走 CMI，这才算实打实的 CMI 线路。
- 有的只在移动侧用 CMI，电信和联通用户买回去，走的还是普通线路。

还有一个常见的混淆是 CMIN2。它跟 CMI 不是一回事，是移动后来推出的更高级网络，在 DMIT 的美国洛杉矶产品上出现得更多（LAX Eyeball 就是 CMIN2 回程）。香港这边主打的一直是 CMI。拿"香港 CMI"和"洛杉矶 CMIN2"比速度，比的是两个机房、两条网络，得不出有效结论。

## 几个经常被问的问题

**CMI 一定比 CN2 GIA 快吗？**
不一定。对你所在的运营商而言，自家线路通常更顺。移动用户走 CMI、电信用户走 CN2 GIA，这是最省事的搭配；反过来买，未必比普通线路好。

**香港 EB 的 CMI 是双向的吗？**
按第三方多次测评记录，移动侧是去回程都走 CMI，联通回程为 CUG + CMI 动态负载，电信回程走 163PP。所以严格说它是"移动双向 CMI + 其他网侧尽力优化"，不是三网都双向 CMI。

**现在还能买到老款三网 CMI 的香港 Eyeball 吗？**
买不到了。HKG EBv2 已在 2026 年 8 月停服退场，现在能买的是 AS3 / AN5 平台的新一代 HKG.EB。

**三个系列之间能升级切换吗？**
一般只能在同系列内升级配置，跨线路系列通常需要重新购买，这一点最好在下单前想清楚。

**"香港 CMI VPS"到底值不值？**
如果你或你的访客主要在移动网络，值——CMI 是移动自家的国际线路，绕路少、波动小。如果主要是电信和联通的用户，同样的预算放在 Pro 上，体验大概率更稳。搞清楚这一点，你在香港 VPS 上花的每一笔钱才落在对的地方。
